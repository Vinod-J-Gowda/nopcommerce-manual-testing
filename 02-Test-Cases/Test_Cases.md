# Test Cases – nopCommerce E-Commerce Application

## Registration Test Cases

| Test Case ID | Scenario ID | Test Case Description                                | Preconditions                     | Test Steps                                                                     | Test Data                                                      | Expected Result                                                                           |
| ------------ | ----------- | ---------------------------------------------------- | --------------------------------- | ------------------------------------------------------------------------------ | -------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| TC-001       | TS-01       | Verify registration with valid mandatory details     | User is on registration page      | Enter valid mandatory details and submit the registration form                 | Valid first name, last name, email, password, confirm password | Customer account should be created successfully                                           |
| TC-002       | TS-02       | Verify registration with valid optional details      | User is on registration page      | Enter valid mandatory and optional details and submit                          | Valid customer information                                     | Registration should complete successfully                                                 |
| TC-003       | TS-03       | Verify registration with an already registered email | A customer account already exists | Enter an existing email with otherwise valid details and submit                | Existing registered email                                      | Duplicate registration should be prevented and an appropriate message should be displayed |
| TC-004       | TS-04       | Verify registration with invalid email format        | User is on registration page      | Enter an invalid email format and submit                                       | `vinod@invalid`                                                | Appropriate email validation message should be displayed                                  |
| TC-005       | TS-05       | Verify registration with mandatory fields blank      | User is on registration page      | Leave required fields blank and submit                                         | Blank required fields                                          | Required-field validation messages should be displayed                                    |
| TC-006       | TS-06       | Verify password and confirm-password mismatch        | User is on registration page      | Enter valid details with different password and confirmation values and submit | Password: `Test@12345`, Confirm: `Test@12346`                  | Registration should be prevented and password mismatch validation should be displayed     |
| TC-007       | TS-07       | Verify password boundary and requirement validation  | User is on registration page      | Enter passwords around the application's allowed length and format boundaries  | Boundary password values                                       | Application should enforce the defined password requirements                              |

| ------------ | ----------- | ------------------------------------ | ---------------------------------- | ----------------------------------------------------------------------- | -------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| TC-008       | TS-08       | Verify login with valid credentials  | Registered customer account exists | Enter valid email and password and select Login                         | Valid registered credentials     | Customer should be logged in successfully                                                                  |
| TC-009       | TS-09       | Verify login with invalid password   | Registered customer account exists | Enter valid email and incorrect password and select Login               | Valid email + incorrect password | Login should fail and an appropriate error message should be displayed                                     |
| TC-010       | TS-10       | Verify login with unregistered email | User is on login page              | Enter an unregistered email and password and select Login               | Unregistered email               | Login should fail and an appropriate error message should be displayed                                     |
| TC-011       | TS-11       | Verify login with blank credentials  | User is on login page              | Leave email and password blank and select Login                         | Blank credentials                | Appropriate required-field validation should be displayed                                                  |
| TC-012       | TS-12       | Verify email validation during login | User is on login page              | Enter an invalid email format and password and select Login             | `vinod@invalid`                  | Appropriate email validation should be displayed                                                           |
| TC-013       | TS-13       | Verify Remember Me functionality     | Registered customer account exists | Enter valid credentials, select Remember Me, and log in                 | Valid credentials                | Remember Me functionality should behave according to the application's design                              |
| TC-014       | TS-14       | Verify logout and session behavior   | Customer is logged in              | Select Logout and attempt to access authenticated account functionality | Valid logged-in session          | Customer should be logged out and authenticated functionality should no longer be accessible without login |
