# Test Plan – nopCommerce E-Commerce Application

## 1. Project Title

Manual Testing of nopCommerce E-Commerce Web Application

## 2. Objective

The objective of this project is to perform systematic manual testing of an e-commerce web application and validate its major user-facing functionalities, business workflows, input validations, and end-to-end purchase journeys.

## 3. Application Under Test

**Application:** nopCommerce Demo Store
**Application Type:** E-Commerce Web Application
**Testing Type:** Manual Testing

## 4. Testing Scope

The testing scope will include major e-commerce functionalities such as:

* User Registration
* Login and Logout
* Product Search
* Product Categories
* Product Details
* Product Sorting and Filtering
* Wishlist
* Shopping Cart
* Checkout
* Address Management
* Order Placement
* Order History
* Input Validation
* Navigation and UI behavior

## 5. Testing Approach

Testing will be performed manually using a web browser.

Test scenarios will be derived from the application's observable functionality and business workflows. Detailed test cases will then be created and executed using appropriate positive, negative, boundary, and end-to-end test conditions.

Defects identified during execution will be documented with reproducible steps, expected results, actual results, severity, priority, and supporting evidence.

## 6. Testing Types

The project will include:

* Functional Testing
* Positive Testing
* Negative Testing
* Boundary Value Analysis
* Equivalence Partitioning
* Smoke Testing
* Regression Testing
* End-to-End Testing
* UI Testing
* Input Validation Testing

## 7. Test Environment

**Application:** nopCommerce Demo Store
**Platform:** Web Application
**Browser:** To be recorded during test execution
**Operating System:** To be recorded during test execution

## 8. Entry Criteria

Testing can begin when:

* The application is accessible.
* The required functionality is available for testing.
* Test scenarios and test cases have been prepared.
* Required test data is available.

## 9. Exit Criteria

Testing will be considered complete when:

* Planned test cases have been executed.
* Test results have been recorded.
* Identified defects have been documented.
* Critical testing workflows have been covered.
* Smoke and regression suites have been executed where applicable.
* A final test summary has been prepared.

## 10. Deliverables

The following deliverables will be maintained as part of this project:

* Test Plan
* Test Scenarios
* Test Cases
* Test Data
* Test Execution Report
* Defect Report
* Smoke Test Suite
* Regression Test Suite
* Test Summary Report

## 11. Out of Scope

The following areas are outside the scope of this manual testing project:

* Test automation
* Performance/load testing
* Security penetration testing
* Source-code testing
* Database-level testing
* CI/CD pipeline testing

## 12. Project Status

**Status:** In Progress
